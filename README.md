# DeCria — Wallpapers & Design

Site estático responsivo com identidade visual vermelha, preta e branca e logo enviada.

## Arquivos
- `index.html` — página e modais de login/publicação
- `style.css` — estilo responsivo
- `script.js` — posts, filtros e demonstração de equipe
- `logo-decria.png` — logo do projeto

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Envie todos os arquivos para a raiz do repositório GitHub.
3. Abra **Settings → Pages**.
4. Escolha **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.

## Login de demonstração
- E-mail: `admin@decria.local`
- Senha: `decria123`

Entre em **Entrar / Equipe** para ver o painel de demonstração. O administrador pode adicionar/remover membros e escolher cargos:
- **Editor:** publicar e editar posts.
- **Moderador:** publicar, editar e excluir posts.
- **Administrador:** gerenciar equipe e todas as ações.

## AVISO IMPORTANTE DE SEGURANÇA
O login deste ZIP é apenas um protótipo local, não autenticação real. As contas e permissões são guardadas no navegador e podem ser alteradas por qualquer pessoa com acesso às ferramentas do navegador. Não use senhas reais nem publique este protótipo como painel seguro. Para uma equipe real por e-mail e permissões compartilhadas entre todos os visitantes, é necessário conectar Supabase/Firebase ou outro backend com autenticação e regras de acesso no servidor. Os links de redes sociais no rodapé são exemplos e devem ser trocados pelos perfis oficiais da DeCria.
